This repository provides code to simulate populations of radio-luminous supernovae and supernova remnants, largely based on the observed properties in the ULIRG Arp 220 (Varenius et. al 2019)

## Installation

git clone https://github.com/makotojohnstone/ASTR5470_FinalProject/
cd ASTR5470_FinalProject
pip install -r requirements.txt

# Install the project as a package
pip install -e .
